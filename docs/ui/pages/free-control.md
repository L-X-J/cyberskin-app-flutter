# 自由控制页

## 基准与布局

- 沿用 UI 索引的 Figma 参考：纵向 `172:3131`、横向 `172:3201`；本次动画依据 2026-10-21 用户明确需求。
- 基准使用 402px 逻辑宽度、Flutter 默认字体、1.0x 文字缩放和固定设备布局数据；不连接真实 BLE 进行视觉验收。
- 保留当前悬浮折叠标题、系统安全区、滚动列表和后台 `(row, col, rows, cols)` 两列画布几何；动画不改变控件尺寸和排版。

## 动画约定

- 页标题与首页 Free control 卡片共享 Hero；飞行过程中插值文字样式，并把 mode 从第二行移到首行末尾。标题落位后继续响应原有滚动折叠。
- `cols == 1` 的组件从所属列的屏幕侧边滑入；`cols >= 2` 的组件淡入并从底部上移。
- 网格首次挂载播放 760ms 入场，按实际行顺序小幅错开，最多延迟四档；布局异步加载完成后才挂载网格。
- 遥测、开关收折、窗口变化和普通 rebuild 不重播入场，也不触发新的设备指令或重置控件状态。
- 系统减少动态效果时直接展示最终位置。快速返回时动画随 Widget 销毁，控制器正确释放。

## 验收范围

- 复用已有组件和文字 token，校验标题前进/返回衔接、左右入场、双列淡入上移、滚动折叠、窄屏/横屏/大字体及减少动态效果。
- 截图和执行结果随本次交付报告；静态截图只能确认取样帧，实机流畅度需另行验收。
