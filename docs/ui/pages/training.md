# Training 页面与首页真实内容

设计参考：Ardot `729272102282180`，列表 `172:3547`、详情 `172:3575`。基准 402×874，使用项目默认字体。训练封面只使用服务端发布 URL，加载失败显示占位图标，不使用示例课程。

## 页面与交互

- `/training`：玻璃课程列表、名称与时长／段数／强度摘要。当前实际连接型号优先，其次当前账号绑定型号；没有型号时查询全部。刷新失败保留旧课程，初次错误提供 Retry，空列表明确显示空态。
- `/training/info/:id`：路由摘要提供首帧，详情元数据与已发布能力加载后可点击 Start，届时下载/校验完整 JSON 后才启动。没有摘要时按 ID 加载；下架课程显示服务端错误及重试，不能启动。
- 进入详情只预览，Start 才开始。运行、暂停、中断时按钮为 Stop；确认停止或自然完成后留页 Restart。返回保留运行，浮动控制暂停／继续共享公共播放器，恢复必须是同一物理设备；相对指令无法安全恢复时要求结束重启。
- 预览和运行使用不同快照，浏览 B 不改变正在运行的 A。开始后冻结完整课程与能力编译结果，断网不中断已加载序列；本轮没有跨重启课程离线库。
- 列表标题与首页 Training mode 标题使用 Hero；课程标题包含入口和课程 ID。异步详情更新保持 tag，不重新播放转场。
- 首次列表入场使用公共 AppListEntrance：360ms、45ms 错峰，延迟上限五级。页面记住已出现的课程，刷新／计时不重播；系统减少动态效果时直接显示终态。

## 布局约定

- 页面左右 22，最大内容列 600；SafeArea 消费系统 inset。正文正常滚动，返回区和底部按钮固定，低高度窗口仍能滚动访问内容。
- 详情目的入口直接预览返回 HTML，弹窗使用原 HTML 渲染完整说明。约 202 逻辑像素粉色圆盘与 Time 卡片均消费公共引擎的总剩余时间；Minutes 由真实总秒数换算，Intensity 原样展示后台发布的 1–10。
- 字体增大时圆盘按内容扩展并受宽度约束；指标卡在局部宽度不足 300 或 16px 字体缩放后大于 23 时纵排，内容自然增高，不锁定文字缩放或整页缩放。
- 复用 AppLottieBackground、AppGlassCard、AppLiquidGlassButton 及主题色。字体与 Ardot MiSans 的差异保留由人工验收。

## 首页

- `GET /app/v1/home?deviceModelId=...` 一次获取最多三条课程及三条广告；仅展示首条训练，More 进入完整目录。空数据不显示示例课程。
- Banner 可横滑，默认每五秒切换；单条、拖动、首页被路由覆盖、切换 Video、App 后台或减少动态效果时暂停，回到可见状态后重新计五秒。
- product_detail 跳转对应设备产品详情；external_url 只接受具有主机的有效 HTTP(S) 地址。
- 内容与设备加载分别拥有世代及加载状态；BLE 初始化／发现不等待内容，型号变化丢弃旧响应；刷新失败保留已有真实内容。
