## 参数进入代码的门槛

只有满足以下条件的参数才可成为全局 token：

1. 有可追溯的设计来源或明确产品要求。
2. 语义与变化原因稳定，例如 `surfaceControl`, `contentMaxWidth`, `cardRadiusLarge`，不是 `purple2` 或 `gap17`。
3. 至少两个稳定使用点，或主题/无障碍契约明确需要。
4. 在目标 Flutter 平台和基准截图中校准过。

单页面、待确认或仅为临时设计状态的数值写进页面布局约定，而不是全局 theme。大屏断点、最大宽度和栅格列数同样需要内容依据；当前没有已确认的全局断点 token。

## 资源与图标规则

- Figma 临时导出链接有时效，不能写入应用源码或文档作为正式资源路径。
- 下载并确认授权后的资源放入项目约定的素材目录，声明到 `pubspec.yaml`，并在页面约定记录来源节点和用途。
- 动态设备图、广告图和后台内容图走其数据模型/远端内容契约，不打包成设计稿静态替身。
