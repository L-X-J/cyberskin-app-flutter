# 页面与组件布局约定模板

为实质性页面实现新建一份页面约定，例如 `docs/ui/pages/device-home.md` 或 `docs/ui/pages/free-control.md`。可以删除不适用章节，但必须保留设计来源、基准、状态、适配策略和待确认项。

```md
# <页面或组件名称>

## 来源与状态

- PRD：`docs/...` 第 <章节>。
- Figma：`<文件 URL>`，节点 `<id>`；最后读取：`YYYY-MM-DD`。
- 设计版本：<版本/日期/未知>。
- 验收状态：未实现 / 静态实现 / 基准已验收 / 适配已验收。

## 基准环境

| 项目 | 值 | 证据/说明 |
| --- | --- | --- |
| 逻辑尺寸 | <宽 x 高> | Figma 画板；确认导出倍率。 |
| 平台与系统区域 | <iOS/Android、状态栏/底部 inset> | 设计或测试设备。 |
| 字体与文本缩放 | <字体、1.0x> | 字体注册状态与设计标注。 |
| 固定数据 | <设备名、连接状态、档位、图片> | 可复现基准截图。 |
| 动画/异步状态 | <冻结方式> | 避免截图偶发差异。 |

## 页面区域

| 区域 | 类型 | 规则 |
| --- | --- | --- |
| 顶部栏 | 固定 / 随滚动 | <安全区、标题、操作> |
| 主内容 | 滚动 / 固定 | <内容与最小/最大约束> |
| 全局 pill | 悬浮 / 底部栏内 | <与导航、键盘和可达性的关系> |
| 背景/光晕 | 装饰 | <裁切、缩放、是否忽略指针> |

## 布局约束

### 横向

- 内容边距：<token 或页面值及来源>。
- 最大宽度与对齐：<规则；没有依据时写“待确认”>。
- 列、列间距和重排条件：<由可用宽度与内容决定，不按设备型号>。
- 窄屏降级：<单列/横向滚动/换行/其他>。

### 纵向

- 固定高度：<仅列出确有固定交互尺寸的元素>。
- 内容驱动区：<文本、卡片、列表的增高/滚动规则>。
- 底部占位：<导航、pill、键盘和 safe area>。
- 低高度：<内容优先级、滚动与悬浮策略>。

## 文本、图片与视觉

- 文本：<style token、最大行数、溢出策略、长名称策略>。
- 图片/素材：<asset source、比例、fit、对齐、内部留白>。
- 视觉组件：<卡片/渐变/玻璃/滑杆等的 token 和组件引用>。
- 语义与输入：<按钮 label、键盘焦点、触控区域、禁用状态>。

## 数据与状态

- UI 状态来源：<GetxController 字段/领域模型>。
- 固定预览数据：<基准截图用 fixture；不得触发真实 BLE/API>。
- 状态：默认、选中、禁用、加载、空态、错误、连接中、运行中等。
- 副作用边界：<重建/窗口变化/截图不得导致的网络或 BLE 行为>。

## 适配策略

| 场景 | 预期行为 | 验收方式 |
| --- | --- | --- |
| 窄屏 | <规则> | <截图/Widget test> |
| 宽屏或横向窗口 | <最大宽度/重排> | <截图> |
| 低可用高度 | <滚动/固定区> | <截图> |
| 大字体 | <换行/增高/重排> | <截图/语义检查> |
| 键盘 | <可达输入和提交操作> | <交互截图> |
| 长内容/空态/错误态 | <规则> | <截图> |
| 窗口变化 | <状态与滚动保持> | <交互验证> |

## 冲突、待确认与验收记录

- 冲突：<Figma 与 PRD 的差异、临时依据、影响和需要决策的人>。
- 待确认：<不能从设计、PRD 或现有实现得出的信息>。
- 截图：`<相对路径或测试产物路径>`，关联提交/数据/节点 `<id>`。
- 未验证项：<运行环境、字体、真机等限制>。
```

自由控制页还应额外记录：后台模块类型、样式、排列、`gridColumns`、每种配置在窄屏/大字体下的降级策略，以及模块状态与设备指令之间的单一状态来源。
