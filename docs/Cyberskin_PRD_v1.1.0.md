# 第一部分 App 端

## 文档说明与关键假设

本 PRD 基于最新原型图及需求澄清整理。全局性结论如下：

- **平台形态**：原生 App（iOS / Android）。
- **语言**：仅英文，全文 UI 文案以英文为准；本文档括号内的中文仅为说明。
- **设备能力驱动 UI（核心原则）**：各型号支持的功能点、档位、模式、控制页布局等，均由管理后台配置；客户端按「设备能力模型 + 布局配置」动态渲染，不同硬件适配与页面调整均无需发版。
- **模式（Mode）机制全 App 统一**：模式为**设备固件内置的波形预设**（固件定义，后台不可编辑波形本身）；由后台配置**对 App 暴露的模式数量与显示名称**（如 "Mode 1/Mode 2/Mode 3"、"Easy Mode"、"one/two/three" 等均为后台自定义命名）。自由控制、自定义节奏使用同一套模式配置。
- **无级变速与模式叠加**：模式决定波形，无级变速（Variable Speed，0–100%）滑杆调节该模式的执行速度与强度，两者叠加生效。伸缩通道支持无级变速；其他通道是否支持无级变速由设备能力模型决定。

## 1.产品概述

### 1.1项目背景

Cyberskin 为面向美国男性用户的智能情趣硬件（飞机杯）品牌。文档中的 Cyberskin Air / Pro 为概括性示意型号，代表品牌下多款不同能力档位的蓝牙设备；实际设备型号目录由管理后台配置，后台支持添加多台设备，每台设备的功能点不同。本 App 作为统一操控入口，提供设备连接、自由控制、自定义节奏、训练模式、视频联动与个人账户等能力；管理后台作为配置与运营中枢，驱动 App 的全量功能（见第二部分）。

### 1.2目标用户

- 地域：美国；性别：男性；语言：英文。
- 核心诉求：便捷、可定制地控制设备；节奏训练与视频联动。

### 1.3目标与范围

- 目标：稳定可靠的蓝牙连接与控制、积木式自由控制、片段式自定义节奏、训练模式、视频联动、广告位运营。
- 范围（v1.1.0）：账号登录（Apple / Google / 邮箱验证码）、设备连接与绑定、自由控制（积木式布局）、自定义节奏（片段模型）、训练模式、视频（官方/浏览器/本地）、首页广告位、个人中心、反馈。

### 1.4名词表

| 名词                  | 说明                                                               |
| ------------------- | ---------------------------------------------------------------- |
| Device / 设备         | 蓝牙硬件（以 Cyberskin Air / Pro 等为示例型号，实际以管理后台配置的多款设备为准）              |
| 片段 Segment          | 自定义节奏的基本单元：持续时间 + 各通道状态（伸缩模式与无级变速/震动开关/吮吸模式）                     |
| 模式 Mode             | 设备固件内置波形预设；后台配置对 App 暴露的数量与显示名称（伸缩/吮吸等通道适用）                      |
| 无级变速 Variable Speed | 0–100% 连续调节，与模式叠加，调节执行速度/强度                                      |
| 模块 Module           | 自由控制页的可拼装控件单元（Heat/Suck/Telescopic/Vibration/One click climax 等） |
| 积木式布局               | 后台按型号拖拽模块、样式与排序，生成设备控制页；统一引擎渲染，适配硬件无需发版                          |
| One click climax    | 一键执行后台配置的预设高潮节奏序列                                                |
| 设备能力模型              | 后台按型号下发的"支持功能点/档位/模式/加热"配置                                       |
| 广告位                 | 首页底部运营位，后台配置多位轮播                                                 |

## 2.全局规则

### 2.1账号与数据

- **登录方式**：Apple、Google、**邮箱 + 6 位验证码**（Continue with email）三种（详见第 4.2 节）。
- **单点登录（SSO）与会话策略**：App 不维护独立密码体系；Apple/Google 走 OAuth 单点登录，邮箱走验证码免密登录。同一账号可在多台设备同时登录，不强制单端独占、不做强制下线；多端数据通过云端同步，冲突以「最后写入」为准。登出仅清除本端会话。
- **新用户首次登录后必须补充昵称与头像**：跳过则默认昵称为邮箱前缀，默认头像为邮箱首字母占位（例如邮箱 `zhang@apple.com`，默认昵称为 `zhang`，头像显示 `Z`）。
- **数据策略**：云端同步 + 本地缓存。自定义节奏、训练记录、账户资料云端同步；**离线状态下仍可使用设备控制与本地已缓存内容**。

### 2.2设备能力模型（后台驱动）

客户端连接设备后，从服务端获取该型号的「设备能力模型 + 布局配置」，动态渲染控制界面：

- `supportedActions`：支持的功能点集合，如 `[thrust, vibration, suck, heat]`；每个功能点含 `gearMax`（档位数，如伸缩 0–6 档）、`defaultValue`。
- `variableSpeedSupported`（按通道）：是否支持无级变速（0–100%）。
- `modes`（按通道）：对外暴露的模式列表（数量与显示名称由后台配置，模式本体为固件内置波形预设）。
- `heatSupported`（布尔）+ `heatLevels`：是否支持加热及温度档位；不支持则不渲染加热模块。
- `layoutConfigRef`：该型号在后台配置的自由控制积木式布局（模块、样式与排序，见第 6.2 节）。
- 不同型号能力不同时，控制页自动差异化渲染；**切换产品类型（如带伸缩杆产品更换为仅带吮吸头产品）时，仅需在后台重新拖拽配置，控制界面即同步更新，无需修改代码、无需重新设计界面。**

### 2.3状态枚举与提示

所有连接与运行状态的定义见第 12 章，均按枚举渲染，禁止静默失败。

### 2.4后台/前台行为

- App 切后台或锁屏：设备保持运行，不自动暂停。
- 来电或系统弹窗打断：设备暂停；回到 App 点击 pill 恢复。
- 设备端物理按键与 App 指令双向同步：设备状态变化实时回传 App，App 主动指令下发设备。

### 2.5体验规范

- 加载骨架屏、转场动画、操作震动反馈（haptics）。
- 视觉、色值与字体以设计系统（UI）为准。

### 2.6数据埋点原则

- **使用 Google 系第三方统计/埋点 SDK**。

## 4.启动与登录

### 4.1启动页 Splash

- 展示品牌 Logo（Cyberskin），短暂启动后进入登录页（已登录且资料完整则直达设备主页）。

### 4.2登录页 Login

- 登录方式（三种）：
  - **Sign up with Apple**：调用系统 Apple 登录，获取身份与邮箱。
  - **Sign up with Google**：调用 Google 授权登录。
  - **Continue with email**：进入邮箱验证码登录流程。
- **邮箱登录流程**：
  - 步骤一 "Your Email"：输入邮箱，点击 **Next**；校验邮箱格式，非法则内联提示 "Please enter a valid email."。
  - 步骤二 "6-digit code"：提示 "Enter the code sent to {email}"；6 位验证码输入框（3+3 分组展示）；底部 **Sign in** 提交。
  - 验证码：60 秒倒计时后可重发（"Resend code in 00:54"）；验证码有效期 5 分钟（由后台配置）；输错提示 "Incorrect code. Please try again."；过期提示 "Code expired. Please resend."；发送频率超限提示 "Too many requests. Try later."。
- 页面底部文案：**"By tapping Continue, you are agreeing to our Terms of Service and Privacy Policy"**，ToS / Privacy Policy 为可点击链接（内容由客户提供、由管理后台配置维护）。
- 状态：授权或发送中时按钮 loading 并禁用其他操作；成功后，新用户进入资料补充页，老用户进入设备主页；失败或取消时 Toast 提示并停留本页。
- 异常：无网络时点击登录或发送验证码，提示 "Network unavailable, please try again."。

### 4.3资料补充 Profile Setup

- 触发：新用户（任一登录方式）首次登录后强制。
- 昵称（必填，空值拦截 "Nickname is required."）；头像（非必填，跳过则使用默认头像）。
- 完成：保存后进入设备主页。

## 5.设备连接与绑定

### 5.1添加设备 Add Device

- 入口：我的设备页 "Add Device" 按钮。
- 页面构成：
  - 顶部提示："Turn on Bluetooth and keep the device nearby."。
  - 设备型号列表：**由管理后台配置**（后台支持添加多台设备，每台设备功能点不同；如 Cyberskin Air、Cyberskin Pro 为示意型号）。该列表为按型号进入图文详情的入口，非实时扫描列表。
- 交互：
  - 点击某型号卡片后，进入该型号的「产品详情页」（图文内容，只读，见第 5.3 节）。
  - 产品详情为图文说明，**具体的连接、绑定与操控操作需返回「我的设备」首页进行**（见第 5.2 节），不在详情页内发起实操。

### 5.2我的设备 My Devices（设备主页）

- 页面结构（自上而下）：
  - 标题 "My Devices" + 问候语（如 "Good evening, stay relaxed"）+ 右上角头像（进入个人中心）。
  - **设备卡片**：设备图（后台配置的设备图标）、名称、连接状态（`Connected/Connecting/Disconnected/Low Battery`）、电量（如 67%）、电源按钮、**Product manual** 按钮（跳转产品详情）。
  - **Free control mode 卡片 / Custom rhythm 卡片**（带预览图标，进入对应模块）。
  - **Training mode 卡片**：More 按钮 + 课程条目（名称、时长、阶段数、强度）。
  - **广告位 Banner**（见第 10 章）。
  - 底部：Device / Video Tab + 全局 pill。
- 连接发起（实际操作入口）：从设备卡片点击"连接"发起真实连接流程：
  - 首次连接或无蓝牙权限时，弹出系统蓝牙权限请求；拒绝后引导去系统设置。
  - 蓝牙未开启时，提示开启蓝牙。
  - 状态流转见第 12 章：`Connecting` 至 `Connected`；失败或超时提示 "Connection failed. Please try again."（可重试）；扫描超时未命中提示 `Not Found`。
- 快捷入口：自由控制 / 自定义节奏 / 训练模式（指向已连接设备）；已绑定多台时支持手动切换当前设备（不自动重连）。
- **重连策略：不自动重连，由用户手动触发**（设备卡片或全局 pill）。

### 5.3产品详情 Product Detail

- 入口：添加设备页型号卡片；或设备卡片 "Product manual"。
- Tab：Product Intro / Connection / Cleaning，图文内容由后台配置（英文）。
- 行为：纯只读图文说明，支持 Tab 切换与返回；不含任何连接或控制实操。

## 6.自由控制 Free Control

### 6.1设计目标

- 自由控制页存在**多种排版样式**，由管理后台**按设备型号排列组合**生成。
- 具体装配流程（后台操作，见第二部分第 17.4 节）：将所需模块**拖拽**至移动端控制界面框内（部分功能提供多种样式供选择，如横向排版或纵向排版），即完成对应硬件的装配。
- 切换产品类型（如将原带伸缩杆的产品更换为仅带吮吸头的产品）：仅需**重新拖拽生成一套模块组合**，控制界面即同步更新，**无需修改代码、无需重新设计界面**。
- 方案依托**统一渲染引擎**，通过模块拼装适配不同硬件，解决两个核心问题：**更快的硬件适配**、**灵活的页面调整**。

### 6.2模块库与样式枚举

| 模块               | 样式选项（原型）                                                                          | 说明                                  |
| ---------------- | --------------------------------------------------------------------------------- | ----------------------------------- |
| Heat             | A：开关卡（2×2 网格内）；B：横向条卡（"Not enabled" + 火焰图标 + 开关）                                  | 开关式；温度档位由 `heatLevels` 配置，多档时展示档位选择 |
| Suck             | A：开关卡；B：模式卡（开关 + 模式芯片列表，芯片文案后台自定义，如 "Easy Mode / Quick Mode / one / two / three"） | 模式数量与名称由后台配置                        |
| Telescopic       | A：纵向档位条（自定义档点选）；B：分段横向条（自定义档点选）；C：无级变速横向条（拖动）；D：纵向百分比滑杆（0–100%）                   | 档位模式与无级变速样式按能力模型提供                  |
| Vibration        | 同 Telescopic 的 A/B/C/D 样式                                                         | 同上                                  |
| One click climax | 卡片（波形预览 + 电源按钮）                                                                   | 一键执行后台配置的预设高潮序列                     |

- 布局规则：后台按型号从模块库选择模块，为每个模块选定样式并拖拽排序；网格默认 2 列（由后台配置为 1 列或 2 列）；每型号同一时间仅生效一套布局。

### 6.3交互规则

- **进入页面即按当前模块值自动运行**（无需额外 Start），底部 pill 显示 `Running`；点击 pill 暂停，再次点击恢复至暂停前状态（非归零）。
- 模块调节**实时下发**设备（档位点选、滑杆拖动、开关切换）。
- **One click climax**：点击执行后台配置的预设高潮节奏序列，执行完成后自动结束；运行中再次点击可提前停止；执行期间覆盖各通道手动参数。
- Heat：开关式；开启后按当前档位目标温度执行；关闭不影响电机。
- 暂停恢复、断连、低电量等状态遵循第 12 章的状态枚举。

## 7.自定义节奏 Custom Rhythm（片段模型）

自定义节奏中要根据不同的设备识别出对应的

### 7.1节奏列表 Rhythm List

- 页头：Custom rhythm + 当前设备名与连接状态（如 Cyberskin Pro · Connected）。
- 卡片：日期徽标 + 节奏名（如 User-defined·01）+ 适用设备名；点击卡片运行（需当前连接设备匹配适用型号，不匹配则提示切换设备）。
- FAB **+** 新建；底部全局 pill 展示当前运行状态。
- 删除整条节奏：**需二次确认**（删除入口遵循 UI 设计稿）；确认文案 "Delete this rhythm? This cannot be undone."（Cancel / Delete）。

### 7.2新建/编辑节奏 Rhythm Editor

- 字段：
  - **Rhythm name**：必填；未命名不允许保存，提示 "Please name this rhythm."。
  - **Applicable Devices**：必选型号；节奏仅对该型号可用。
  - **Set rhythm（片段列表）**：有序片段序列。
- **片段卡**：持续时间（如 "This segment lasts 10s"）+ 各通道状态 chips（伸缩速度：模式 + 无级变速值；震动：已开启；吮吸：模式）+ 垃圾桶图标（**删除片段无需二次确认**）。
- **添加片段弹层（Add segment sheet）**：
  - **Duration（持续时间）**：`1s / 3s / 5s / 10s / 30s / 1m / 2m`，支持自定义输入（范围 1s–2m）。
  - **Thrust Speed（伸缩速度）**：开关 + 模式芯片（Mode 1/2/3，数量与名称由后台配置）+ **Variable Speed 无级变速滑杆（0–100%，与模式叠加）**。
  - **Vibration（震动）**：开关（是否支持模式由能力模型决定）。
  - **Suck（吮吸）**：开关 + 模式芯片。
  - 各通道可任意组合开启。
  - 底部按钮：**Add more（继续添加，保存当前片段并继续配置下一段）/ Confirm（确认）**。
- **约束**：最多 **30 个片段**；超出提示 "Maximum 30 segments reached."。
- **Save 校验**：名称非空、至少 1 个片段、适用设备已选；否则拦截并提示。
- **进入编辑器的暂停确认（Prompt 弹窗）**：若设备正在运行，进入创建或编辑节奏时弹窗："During rhythm creation, the device will pause automatically. Continue?"（Cancel / Confirm）；确认后设备自动暂停并进入编辑器。**编辑过程不驱动设备。**

### 7.3节奏运行 Rhythm Runner

- 进入：列表点击节奏（设备型号需匹配）。
- 展示：
  - 页头：设备名 + 连接状态；右上角 **Edit**（点击暂停运行并进入编辑器）。
  - 节奏名（如 User-defined·01）+ **总计片段数**（Total segments: N）。
  - 环形计时器（Time，如 05:20；当前片段剩余与总剩余时间遵循 UI 设计稿）。
  - **当前片段卡**（高亮）："This segment lasts 10s" + 通道 chips + 倒计提示 "Next segment in 12s"。
  - **下一片段预览卡**（置灰）。
  - 底部 **End training**：停止设备并返回列表。
- 规则：页面内不提供暂停按钮（仅 End）；但**全局 pill 可暂停或继续当前运行的节奏**（暂停保留进度，继续从断点恢复）。片段按序执行，全部片段执行完毕后自动结束。
- 异常：运行中设备断开时提示需手动重连，节奏进度保留等待。

## 8.训练模式 Training

- 课程列表：由后台配置、联网获取，支持后台新增；课程条目展示名称、时长、阶段数、强度（如 Rhythm Adaptation · Beginner's Guide，12 minutes · 4 stages · Low intensity）。
- 课程详情/运行：
  - **Training purpose**：点击弹窗展示完整文案。
  - 训练进度（基于已用时长与总时长）、计时、当前强度（Intensity）、总分钟数。
  - 课程各阶段参数（动作、强度、时长）由后台配置，客户端按配置驱动设备。
  - **仅可停止，不可暂停**（End training 停止设备）；训练完成或停止后提示 "Training complete."（无需报告页）。
  - 网络中断：已缓存课程可继续本地执行；设备断开需手动重连。

## 9.视频模式 Video

- **Official**：类抖音竖向滑动信息流；上下滑动切换、可暂停/继续、可切换视频列表视图；内容由后台提供。
- **Browser**：输入框 "Please enter the link" 输入视频 URL，内置浏览器/播放器播放；不处理内容过滤。
- **Local**：Select local video 从相册或文件选择（MP4/MOV）；格式、大小、时长不限制（以系统能力为上限）；**不上传，全程本地运行分析**；页面展示 "Privacy first" 说明。
- **视频—设备联动（统一规则）**：
  - 波形图（Frequency）实时展示视频音频节奏；设备根据视频节奏自动计算并联动；算法由设备端实现，客户端不介入计算。
  - 播放期间完全交给算法，用户不可手动调节设备强度（与自由控制互斥）。
  - 播放暂停后，联动暂停；切换视频后，按新视频节奏重新联动。

## 10.首页广告位 Ad Banner

- 位置：我的设备页底部（Training mode 卡片下方）。
- 形态：运营位卡片（图片、主标题、副标题，例如 "The GalaxyVoy1 New product launch — 12 modes of vibration heating"）。
- 交互：点击跳转（跳转类型为 App 内产品详情页或外部 H5 链接，由后台配置）；多位时轮播展示。
- 规则：无上线广告时该区域隐藏；曝光与点击均上报埋点（自建埋点）。
- 素材与配置：图片、主标题、副标题、跳转类型与链接、排序、上下架、投放有效期，均由管理后台配置（见第二部分第 20 章）。

## 11.个人中心 Me / Status

- 入口：首页右上角头像（无底部 Tab）。
- Profile：头像与昵称可编辑（默认头像为邮箱首字母占位）。
- 菜单项：
  - **My device**：显示绑定设备数；进入设备管理（列表、切换、重命名、解绑、手动重连；解绑二次确认 "Remove this device?"）。
  - **Privacy and Security**：内容由客户提供，由后台录入维护。
  - **Feedback**：问题描述 + 图片上传；提交成功提示 "Success. We will verify as soon as possible."；「返回」回上一页，「返回首页」回设备主页；提交中按钮 loading。
  - **About Us**：内容由后台配置。
  - **Version Information**：显示版本号；点击 Check for updates。
  - **Log out**：二次确认后登出。

# 第二部分 管理后台

## 15.后台总体说明

- **定位**：Web 端管理后台，是 App 的配置与运营中枢；**App 端所有动态内容（设备、能力、布局、模式命名、视频、广告、图文、内容）均由管理后台配置下发，App 无需发版即可适配硬件并调整页面。**
- **核心设计原则**：
  - 配置驱动：App 不写死任何型号能力与页面布局。
  - 草稿-发布机制：所有配置模块均支持草稿保存与发布，发布后 App 在登录或下拉刷新时拉取最新配置生效。
  - 全量覆盖：后台功能域与 App 功能一一对应，覆盖 App 全量功能（见第 25 章）。

## 16.设置（含账号与角色权限）

> 账号与角色权限统一放在「设置」模块下。

- **管理员账号管理**：管理员列表（账号、姓名、角色、状态、最近登录时间）；新增/编辑/禁用/删除管理员。
- **角色权限（RBAC）**：内置超级管理员/运营/客服等角色，支持自定义角色；权限粒度到**菜单可见性 + 操作权限**（查看/新增/编辑/删除/发布）。
- **基础账号功能**：修改登录密码（校验旧密码）、重置密码、修改姓名/头像、操作日志（记录关键操作人与时间）。
- 登录：账号 + 密码登录；连续登录失败锁定策略（锁定阈值与时长由后台配置）。

## 17.设备管理

- 设备列表、新增/编辑基本信息、能力与功能点配置、自由控制积木式布局配置均围绕单台设备展开，合并在同一菜单下。基本信息、能力与布局三项配置在同一设备详情页内顺序完成：① 新增/编辑设备基本信息；② 配置该设备的能力与功能点；③ 配置该设备的自由控制积木式布局。

### 17.1设备列表

- 展示：设备图标、设备名称、硬件唯一标识、蓝牙类型、状态（启用/禁用）、最近更新时间。
- 操作：搜索（名称/唯一标识）、筛选（状态/蓝牙类型）、新增、编辑、启用/禁用、删除（二次确认；已被用户绑定的设备删除需先确认影响）。

### 17.2新增/编辑设备（基本信息）

- 字段与原型一一对应：

| 字段         | 必填   | 说明                                           |
| ---------- | ---- | -------------------------------------------- |
| 设备图标       | 是    | 图片上传；App 设备卡片与添加设备列表展示                       |
| 设备名称       | 是    | 如 MetaCore；App 内展示名                          |
| 硬件唯一标识     | 是    | 如 ECA3FE9A0319C103；BLE 扫描广播匹配依据，App 按此过滤目标设备 |
| 硬件扩展标识     | 条件必填 | **开启扩展联合锁定时填写**；用于扩展配件与主设备的配对校验              |
| 蓝牙类型       | 是    | 下拉选择（当前为 BLE，预留其他类型扩展）                       |
| BLE 读服务特征值 | 是    | 如 ae30                                       |
| BLE 读特征值   | 是    | 如 ae02（状态/数据上报通道）                            |
| BLE 写服务特征值 | 是    | 如 ae30                                       |
| BLE 写特征值   | 是    | 如 ae01（指令下发通道）                               |
| 扩展联合锁定     | 是    | 是/否；开启后配件需凭扩展标识与主设备配对校验                      |
| 状态         | 是    | 启用/禁用；**禁用后 App 端添加设备列表不展示、已绑定设备不可连接并提示**    |

### 17.3设备能力与功能点配置

- `supportedActions`：勾选该设备支持的功能点（伸缩/震动/吮吸/加热等，功能点字典由后台维护，支持新增功能点）。
- 每功能点参数：`gearMax`（档位数）、`defaultValue`、`variableSpeedSupported`（是否支持无级变速）。
- **模式配置**：按通道配置对 App 暴露的**模式数量与显示名称**（App 内"模式1/2/3""Easy Mode""one/two/three"等文案均来自此配置）；模式本体为固件内置波形预设，后台不可编辑波形。
- 加热配置：`heatSupported` + `heatLevels`（温度档位列表）。

### 17.4自由控制积木式布局配置

- **配置对象**：按设备型号配置一套控制页布局；每型号同一时间仅一套生效版本。
- **操作流程（与需求描述一致）**：
  1. 从**模块库**将所需模块**拖拽**至移动端控制界面预览框内；
  2. 为每个模块选择**展示样式**（样式枚举见第一部分第 6.2 节，如横向排版或纵向排版）；
  3. 拖拽调整模块排列顺序与网格列数（1 列或 2 列）；
  4. 实时预览移动端效果，保存为草稿，发布生效。
- **模块可用性约束**：模块库仅展示该设备能力模型支持的功能模块（如仅带吮吸头的产品不可拖入 Telescopic 模块）。
- **切换产品类型**：将原带伸缩杆的产品更换为仅带吮吸头的产品时，仅需重新拖拽生成一套模块组合，App 控制界面同步更新，无需修改代码、无需重新设计界面。
- **One click climax 预设配置**：配置一键高潮的节奏序列（片段式参数：持续时间 + 通道模式/无级变速），供 App 一键执行。
- 版本管理：布局配置保留历史版本，支持回滚。

## 18.训练课程管理

- 课程列表：名称、封面、时长、阶段数、强度、状态（草稿/已发布/下架）。
- 课程编辑：
  - 基本信息：名称（英文）、封面图、**Training purpose 完整文案**、总时长。
  - 阶段（Stage）编辑：有序阶段列表，每阶段配置动作参数（通道/模式/无级变速或档位/加热）+ 持续时长；阶段总时长等于课程时长。
- 发布后 App 课程列表联网更新；已发布课程修改走草稿-发布流程。

## 19.官方视频管理

- 视频列表：标题、封面、时长、排序、状态（上架/下架）。
- 操作：上传视频（MP4）、编辑标题/封面、拖拽排序、上架/下架、删除（二次确认）。

## 20.广告位管理

- 广告列表：图片素材、主标题、副标题、跳转类型（**产品详情 / 外部链接**）、跳转目标、排序、状态（上架/下架）。
- 操作：新增/编辑/排序/上下架/删除；多位广告在 App 首页轮播。

## 21.内容管理

- **产品详情图文**：按设备型号配置 Product Intro / Connection / Cleaning 三个 Tab 的图文内容（富文本 + 图片，英文）。
- **Privacy and Security**：App 内该页内容（由客户提供，后台录入/更新）。
- **About Us**：富文本内容。
- **Terms of Service / Privacy Policy**：登录页协议链接目标内容。
- 所有内容支持草稿-发布；App 端拉取缓存。

## 22.用户管理

> App 登录注册对应的用户数据管理，详细记录用户信息、登录时间及绑定账号信息等。

- **用户列表**：用户 ID、头像、昵称、邮箱、注册时间、最近登录时间、登录方式（Apple/Google/Email）、绑定设备数；支持搜索与筛选。
- **用户详情**：
  - 基础信息：注册渠道、资料完整度。
  - **绑定账号信息**：Apple/Google OpenID、邮箱（一个用户可多渠道绑定，展示绑定关系与绑定时间）。
  - **登录记录**：每次登录的时间、方式、IP/设备型号（列表倒序）。
  - **绑定设备**：已绑定设备列表（名称/唯一标识/绑定时间）。
  - 业务数据概览：自定义节奏数、训练完成次数、反馈记录。

## 23.反馈管理

- 反馈列表：用户、问题描述、附图、提交时间、状态（待处理/处理中/已处理）。
- 操作：查看详情、标记处理状态、内部备注；不直接回复用户（v1.1 不做 IM 回复）。

## 24.版本管理

- App 版本列表：版本号、平台（iOS/Android）、更新说明、发布状态、发布时间。
- 检查更新：App 端 Check for updates 调用此接口返回最新版本；支持配置**强制更新**（可设定低于某版本号的 App 强制升级）。
