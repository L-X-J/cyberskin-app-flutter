# rhythm/presentation/widgets

跨节奏页面复用的背景、表面、片段摘要及确认交互。

- `rhythm_title.dart`：首页入口与列表共用的分词 Hero 标题，减少动态效果时禁用飞行。
- `rhythm_dialogs.dart`：节奏确认弹窗及进入编辑器的导航编排。
- `rhythm_page_frame.dart`：节奏页面公共 Lottie 背景、安全区、受控内容宽度和底部操作区；可选全视口顶层槽独立于操作列约束。
- `rhythm_segment_card.dart`：编辑与运行页共用的片段摘要、通道图标和参数标签。
- `rhythm_surface.dart`：节奏专属内发光表面、错误提示和时间格式展示。
